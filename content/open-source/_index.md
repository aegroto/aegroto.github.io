## Notable contributions

Selected merged pull requests to third-party open-source projects:

### Multimedia

- **[larksuite/rsmpeg](https://github.com/larksuite/rsmpeg)** -- <span class="contrib-desc">Rust FFmpeg bindings</span><br>
Improved building and linking of ffmpeg dependencies by using vcpkg to ease the process [[#120]](https://github.com/larksuite/rsmpeg/pull/120).
- **[rust-av/v_frame](https://github.com/rust-av/v_frame)** -- <span class="contrib-desc">Video frame structures from the rav1e ecosystem</span><br>
Strengthened the test coverage for frame allocation, dimensions, and padding behavior [[#43]](https://github.com/rust-av/v_frame/pull/43).

### Game development

- **[luanti-org/minetest_game](https://github.com/luanti-org/minetest_game)** -- <span class="contrib-desc">Base game for Luanti (formerly Minetest)</span><br>
Decoupled tree-growth logic from core game content by introducing a generic sapling-growth registration API, so new tree types can be defined without modifying core code [[#3053]](https://github.com/luanti-org/minetest_game/pull/3053).
- **[jMonkeyEngine/jmonkeyengine](https://github.com/jMonkeyEngine/jmonkeyengine)** -- <span class="contrib-desc">Java 3D game engine</span><br>
Improved build infrastructure and quality assurance by integrating project-wide code-coverage reporting with per-module and aggregated views [[#2714]](https://github.com/jMonkeyEngine/jmonkeyengine/pull/2714).
